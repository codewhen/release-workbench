# Workflow home

Mode: Operate. Extend the existing cool paper, white surface and teal controls.

## Direction contract

THESIS: Start with the local project and its workflows, so a developer can choose the right checklist before entering the canvas.

OWN-WORLD: Retain Workbench typography, flat surfaces, borders, spacing and keyboard focus. Use an actionable list with project paths and truthful execution state.

STORY: Register project folders, find an existing workflow, open its editor, or create a separate YAML configuration without replacing another workflow.

FIRST VIEWPORT: A familiar header, Workflows title and create action, then search/project filter and readable workflow rows. A separate inline form handles adding folders or files.

FORM: Workflow names and descriptions lead; file paths distinguish similarly named projects. Status and run counts support selection. Mobile rows stack with full-width open controls. The signature action is opening a workflow then returning Home without losing its server-side execution.

QUALITY: No fabricated records. Empty, loading, invalid YAML, inaccessible folders, unsaved drafts and running workflows have explicit states. One workflow executes at a time across the library.
