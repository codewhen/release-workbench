# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Python execution engine with a bundled strict TypeScript, React and React Flow frontend.

## Users
Developers and automation authors composing local tests, scripts, service calls and approvals across projects.

## Product Purpose
Create general-purpose typed flowcharts without writing orchestration code; inspect live work and saved evidence in one place.

## Operating Context
Localhost browser and CLI, free self-hosted operation. Preview v3 is installed separately from stable versions. Native Windows acceptance is unverified.

## Capabilities and Constraints
Six card categories; sequential flow, Boolean functions, main-canvas loops, explicit Parallel/Join, run globals, structured recovery, local files/HTTP, interventions, separate function views, library folders, YAML and reports. Layout never changes execution. No arbitrary Go To, recursion, For-each, Switch or legacy conversion.

## Product Principles
- Make execution versus data visible through labels, shapes and color.
- Keep common fields on compact cards; reveal code and execution controls in the details panel.
- Never invent progress, approval or compatibility.
