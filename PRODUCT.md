# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Python package with bundled React/React Flow frontend; selected in the approved implementation plan.

## Users
Developers configuring tests and release checklists for their own projects, including teams maintaining private applications.

## Product Purpose
Create a ten-step workflow without writing YAML, run parallel branches safely, and inspect progress, failures and saved evidence without terminal scrolling.

## Operating Context
Local browser UI and CLI/CI execution on macOS, Linux and Windows. Workflows live in version-controlled YAML. Consuming projects pin the package while retaining their own application commands.

## Capabilities and Constraints
Multi-project workflow library, separate YAML creation, protected Home navigation, canvas, equivalent list view, advanced settings, YAML editing, terminal wizard, dependencies, locks, exclusive jobs, cancellation, progress, reports and manual evidence gates. MIT license. No paid services, remote agents, multiplayer editing or hosted server in v1.

## Product Principles
- One configuration shared by every editing and execution interface.
- Make a simple checklist quick; reveal advanced controls when needed.
- Show measured evidence separately from estimates and manual attestations.
- Preserve private project configuration outside the public engine.

## Accessibility & Inclusion
Keyboard-accessible editing and list view for smaller screens, required by the approved plan.
